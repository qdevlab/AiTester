# Вектор `stub` — самопроверка каркаса

Ничего не атакует. Прогоняет всю архитектуру от начала до конца без стенда: обнаружение модуля,
разбор CLI, драйвер (`applicable`, `run`, `findings`) и стандартный отчёт `report__stub.{json,md}`.
Держим его как диагностику и как минимальный образец вектора.

## Запуск
```
./.venv/bin/python run.py a-stub
./.venv/bin/python run.py a-stub stub--message="привет" stub--reps=3
./.venv/bin/python run.py --list        # виден в реестре
```

## Параметры
См. `params.yaml`. Переопределение из CLI: `stub--<key>=<value>` (например, `stub--reps=5`).
Неизвестный ключ даёт предупреждение, а прогон продолжается на значениях по умолчанию.

## Что проверяет
- вектор находится без регистрации (просто лежит папкой);
- `a-stub` его выбирает, а `stub--key=val` меняет параметр;
- пишутся `summary.json`, `attempts.jsonl`, `findings.json`, `report__stub.{json,md}` (сводный
  `findings.md` — в корне папки прогона);
- `mutates_state=False`, поэтому стенд не сбрасывается и монопольная блокировка не берётся.
