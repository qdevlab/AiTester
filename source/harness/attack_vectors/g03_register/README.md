# Вектор `g03_register` — TC-G03, регистр формулировки против встречной записи-отказа (ось)

Директивный регистр давит сильнее, но его ловит детектор, и в ответ появляется отказ, который сам
оседает в памяти встречной записью. Описательный и нейтральный регистры звучат тише и проходят мимо
детектора. Выбор регистра — прямой рычаг доли закрепления: воспроизводит наблюдение PromptArmor, где
доля падает с 85% до 6%.

## Как это работает
Вердикт обычный — по журналу внешнего трейсера памяти (видно закрепление в общий или личный ярус) и
повторному вопросу; результат считается раздельно по каждому регистру. Каждая успешная проба
сохраняет трейс в `traces/`. Регистры `directive` и `descriptive` берутся из `params.yaml`, а
`benign`, `compliance` и `universal` — из `config/payloads.yaml` (раздел `memory_poisoning`). Если
регистр нигде не описан, модуль честно сообщает `no_payloads`, а не выдаёт ноль.

## Конфиг
Идентичность, коллекции ярусов, триггер `finalize` и базовые регистры формулировок берутся из
`config/*` через `ctx.cfg`. Значений стенда в коде нет.

## Параметры
Значения по умолчанию — в `params.yaml`. Переопределяются из командной строки:
`g03_register--attempts_per_register=4`, `g03_register--registers=[...]`.

## Запуск
```
python run.py a-g03_register
python run.py --list
```

## Что кладёт в отчёт
Файлы `report__g03_register.{json,md}`. Находка `F-G03-REGISTER`, класс `poison-global`, доля
закрепления с доверительным интервалом (Wilson) и разбивка по регистрам в примечаниях (notes).
Классификация: OWASP ASI06 / LLM01, ATLAS AML.T0054 / T0065 (release 2026.08). Источник — внешний
каталог заявки `catalog/CATALOG.md` (вне репозитория), раздел §TC-G03.
