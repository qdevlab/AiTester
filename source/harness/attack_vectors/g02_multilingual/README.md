# Вектор `g02_multilingual` — TC-G02, многоязычная инъекция (ось обхода)

Одна инструкция-правило подаётся на языке, к которому фильтр не готов (французский, испанский,
немецкий, китайский), либо с чередованием языков. Одноязычная проверка по шаблонам такой вариант
пропускает, и правило закрепляется. Успех измеряется отдельно по каждому языку и режиму.

## Как это работает
Вердикт обычный — по журналу внешнего трейсера памяти (видно закрепление в общий или личный ярус) и
повторному вопросу, но внедряемый текст подаётся на разных языках. Результат считается раздельно по
каждой паре `lang:mode`, чтобы увидеть, какой именно язык пропускает фильтр. Каждая успешная проба
сохраняет трейс в `traces/`. Режим `mode=mono` — вся инструкция на одном языке; `interleaved` —
русская обёртка со вставкой на иностранном.

## Конфиг
Идентичность, коллекции ярусов и триггер `finalize` берутся из `config/target.yaml` через `ctx.cfg`.
Метка-канарейка `{marker}` остаётся частью кода на любом языке.

## Параметры
Значения по умолчанию — в `params.yaml`. Переопределяются из командной строки:
`g02_multilingual--attempts_per_variant=5`, `g02_multilingual--variants=[...]`.

## Запуск
```
python run.py a-g02_multilingual
python run.py --list
```

## Что кладёт в отчёт
Файлы `report__g02_multilingual.{json,md}`. Находка `F-G02-MULTILINGUAL`, класс `poison-global`,
доля закрепления с доверительным интервалом (Wilson) и разбивка по языкам в примечаниях (notes).
Классификация: OWASP ASI06 / LLM01, ATLAS AML.T0051 (release 2026.08). Источник — внешний каталог
заявки `catalog/CATALOG.md` (вне репозитория), раздел §TC-G02.
