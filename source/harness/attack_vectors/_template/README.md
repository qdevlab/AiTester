## Настройки
Что берётся из `config/target.yaml` через `cfg`: адреса, учётные записи, ярусы памяти. Никаких
значений, вписанных прямо в код.

## Параметры
См. `params.yaml`. Переопределить из командной строки можно записью `<name>--<key>=<value>` (например,
`<name>--attempts=8`). Неизвестный ключ даёт предупреждение, берётся значение по умолчанию.

## Запуск
```
./.venv/bin/python run.py a-<name>
./.venv/bin/python run.py a-<name> <name>--attempts=8
./.venv/bin/python run.py --list
```

## Что попадает в отчёт
Файлы `report__<name>.{json,md}` в папке прогона (их пишет драйвер). Находки снабжены классификацией
OWASP ASI/LLM, долей успешных проб с доверительным интервалом (Уилсона) и статусом demonstrated или
not-demonstrated. Для атак на память дополнительно сохраняется трассировка успешной пробы
`traces/trace_<датавремя>_<marker>.jsonl` (её пишет `ctx.tracer().save_trace`).
