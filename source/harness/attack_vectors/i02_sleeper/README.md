# Вектор `i02_sleeper` — TC-I02, отложенная активация (спящая запись)

Внедряемый текст безобиден в текущем ходу и потому проходит мимо контроля в пределах того же хода.
Запись закрепляется только после отложенного `finalize` и оживает уже в более поздней сессии. Задержку
доказывает парный срез трейсера — до и после `finalize`.

## Как это работает
Сначала идёт ход с «фактом на будущее», затем снимается предварительный срез трейсера (`get_canary`)
ещё до `finalize` — там должно быть пусто. После `finalize` трейсер снимается повторно и показывает
закрепление, а в более поздней сессии запись всплывает в собранном контексте (видно по трейсу). Пара
срезов `get_canary` вокруг `finalize` и доказывает задержку. Если запись легла в общую память
`policy` (scope=global), она становится доступна и другому клиенту — межклиентский эффект. Каждая
успешная проба сохраняет трейс в `traces/`. Модуль отражает базовое правило харнесса: без `finalize`
внедрённая запись не закрепляется.

## Конфиг
Идентичности, коллекции ярусов и триггер `finalize` берутся из `config/target.yaml` через `ctx.cfg`.

## Параметры
Значения по умолчанию — в `params.yaml`. Переопределяются из командной строки:
`i02_sleeper--attempts=12`, `i02_sleeper--trigger=chat_word`, `i02_sleeper--turns=[...]`.

## Запуск
```
python run.py a-i02_sleeper
python run.py --list
```

ATLAS AML.T0094 / T0051.002 (release 2026.08). Источник — внешний каталог заявки `catalog/CATALOG.md`
(вне репозитория), раздел §TC-I02.
